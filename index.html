Deep Learning-Based Urban Sound Classification and Acoustic Analysis

A pipeline that listens to a short city-sound clip, tags the sources it hears, tracks patterns over time and place, and flags unusual recordings. This page showcases the project’s output.

How it works

Six stages, from raw audio to an analyst-ready dashboard.

1

Audio in

Mono clip, 5 s at 32 kHz. Invalid input (silent, too short, NaN) is rejected before the model sees it.

2

Log-Mel features

64 Mel bands turn sound into an image-like spectrogram. Try it live in the lab below.

3

CNN14 backbone

Pretrained on AudioSet and frozen: 12 convolution layers produce a 2048-D embedding.

4

Sigmoid head

One independent score per class, so overlapping sounds can both be detected.

5

Thresholds and ABSTAIN

Per-class thresholds tuned on validation data. If no class passes, the system abstains.

6

Patterns and anomalies

Hour and location trends, plus an Isolation Forest that flags unusual recordings.

Three approaches compared

Same data, same split, same metrics. The transfer-learning model is the project’s final choice.

MFCC + SVM

Classical baseline: 40 statistics per clip into an RBF-kernel SVM.

Needs no GPU
Weakness discards time structure

CNN from scratch

Three conv layers (32, 64, 128 filters), trained from random weights.

Parameters 94,186
Compute ≈ 380 M MACs per clip

CNN14 transfer (final)

Frozen pretrained backbone plus a Dropout 0.30 → Linear(2048→10) → Sigmoid head.

Trained 20,490 of 80.77 M parameters
Compute ≈ 9.95 G MACs per clip
